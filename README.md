# Trans Aliens - Site Web Professionnel & Haut de Gamme

## Description
Site web vitrine multipage moderne, original et entièrement dynamique pour l'entreprise **Trans Aliens** (Transport, Logistique, Livraison).

## Direction Artistique & Identité Visuelle
- **Palette de couleurs** : Vert forêt (`#203D32`), Vert sauge (`#A8B99A`), Crème (`#EDE8DC`), Beige doré (`#C4A56B`), Charbon (`#292B27`).
- **Style** : Minimaliste, contemporain, typographie élégante (Playfair Display & Inter), compositions asymétriques et espaces généreux.

## Technologies
- HTML5 sémantique
- CSS3 (Responsive Design avec Media Queries)
- JavaScript natif (Gestion du header au scroll, menu mobile, validation du formulaire)

## Structure des fichiers
- `index.html` : Page d'accueil immersive
- `about.html` : Présentation et valeurs de l'entreprise
- `services.html` : Détail des activités (Transport, Logistique, Livraison)
- `expertise.html` : Savoir-faire et compétences clés
- `contact.html` : Formulaire de contact et coordonnées
- `css/style.css` : Feuille de style globale
- `js/script.js` : Interactions dynamiques
